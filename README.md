# T-Invest

**Скилл для ИИ-агента с доступом к вашему брокерскому счёту Т-Инвестиций. Портфель, доходность, аналитика и сделки по вашей команде через T-Invest API.**

Скилл для Claude Code, Codex, OpenCode, Cursor и других агентов, которые понимают Agent Skills и
умеют запускать команды. Вы спрашиваете обычными словами, агент сам вызывает встроенный CLI и
отвечает по реальным данным счёта через [T-Invest API](https://developer.tbank.ru/invest/api), а
не по памяти. Запускать CLI руками не нужно.

Это **инструмент доступа к данным и операциям**, а не инвестиционный советник. Он не оказывает
инвестиционного консультирования и не даёт индивидуальных инвестиционных рекомендаций, подробнее
в [дисклеймере](#дисклеймер).

## Что умеет

| Раздел | Что внутри |
|---|---|
| Портфель | Позиции и P/L, реальная доходность XIRR с учётом пополнений и выводов, структура по классам активов, секторам, валютам, странам и концентрации, календарь купонов и дивидендов, свободные деньги, операции с комиссиями |
| Рынок и бумаги | Котировки, история цены с бенчмарком IMOEX, стакан, лента сделок, индикаторы RSI, SMA и MACD, расписание торгов, карточки активов, облигации с YTM и дюрацией, дивиденды, фундаментал, прогнозы аналитиков |
| Скринеры | Облигации по YTM, сроку и риску, акции по фундаменталу, по всему справочнику с локальным кэшем |
| Информация | Новости, сделки инсайдеров, календарь отчётностей, сигналы стратегий, вотчлист |
| Торговля | Заявки и стоп-заявки. В песочнице свободно, на боевом счёте каждая сделка с подтверждением, в режиме только чтения сделки заблокированы кодом |

Доходность к погашению, дюрацию облигаций и XIRR счёта считает сам CLI, потому что T-Invest API
готовых значений не отдаёт. Для флоатеров, амортизации и бессрочных выпусков YTM честно остаётся
пустой с указанием причины.

## Установка

Нужен **Node.js 20 или новее**. Это единственная внешняя зависимость, весь код собран в один файл,
npm-пакеты и сборка не нужны.

| Способ | Команда |
|---|---|
| Claude Code, как плагин | `/plugin install t-invest --marketplace nyxandro/skills` |
| Claude Code, Codex, OpenCode, Cursor и другие | `npx skills add nyxandro/t-invest-skill` |
| Одной командой, Linux, macOS, WSL | `curl -fsSL https://raw.githubusercontent.com/nyxandro/t-invest-skill/main/install.sh \| bash` |
| Вручную | Скачайте [архив `.skill` последнего выпуска](https://github.com/nyxandro/t-invest-skill/releases/latest/download/t-invest.skill) и распакуйте в папку скиллов агента |

Выберите один способ. Если поставить двумя, Claude Code загрузит скилл дважды. После установки
перезапустите сессию агента.

<details>
<summary>Подробнее о способах установки</summary>

<br>

- Скрипт `install.sh` скачивает скилл, кладёт его в `~/.agents/skills/` и `~/.claude/skills/` и
  создаёт шаблон `~/.config/tinvest/.env` без токенов. Повторный запуск обновляет скилл и не
  трогает уже вписанные токены.
- Плагин и `npx skills` шаблон `.env` не создают. Заведите его, как в разделе
  [Токены и режимы](#токены-и-режимы).
- Архив `.skill` это ZIP. Распакуйте его в папку скиллов, сам файл архива агент не подхватывает.

  ```bash
  unzip t-invest.skill -d ~/.agents/skills/     # или -d ~/.claude/skills/ для Claude Code
  ```

- Установка плагина одной командой работает в Claude Code 2.1.275 и новее. На старой версии
  сначала добавьте каталог командой `/plugin marketplace add nyxandro/skills`.
- С `npx skills` добавьте `-g`, чтобы скилл стоял во всех проектах. Чтобы поставить определённую
  версию, допишите её метку, например `nyxandro/t-invest-skill@v1.1.0`.
- Скилл сам подскажет в `session status`, когда в репозитории появится новая версия.

</details>

## Как пользоваться

Спрашивайте как обычно.

- *Как мой портфель?*
- *Почём я брал Сбер?*
- *Какая доходность у моих облигаций?*
- *Подбери облигации на срок до трёх лет с доходностью повыше.*
- *Когда ближайшие купоны и дивиденды?*
- *Купи 10 лотов Сбера по рынку.* На боевом счёте агент сначала покажет заявку и спросит
  подтверждение.

В начале каждого диалога скилл спрашивает, в каком режиме работать. По умолчанию это `readonly`,
самый безопасный.

## Токены и режимы

У каждого режима свой токен.

| Режим | Переменная | Что это |
|---|---|---|
| `sandbox` | `T_INVEST_TOKEN_SANDBOX` | Песочница, виртуальный счёт и деньги, отдельный контур API |
| `readonly` | `T_INVEST_TOKEN_READONLY` | Боевой счёт только на чтение, сделки невозможны |
| `full` | `T_INVEST_TOKEN_FULL` | Боевой счёт с реальными сделками, по умолчанию выключены |

Токены выпускаются в [личном кабинете Т-Инвестиций](https://www.tbank.ru/invest/settings/), раздел
"Токены T-Invest API", пошагово в
[инструкции по выпуску токена](https://developer.tbank.ru/invest/intro/intro/token). Кладутся в
один файл `~/.config/tinvest/.env`.

```bash
mkdir -p ~/.config/tinvest
cat > ~/.config/tinvest/.env <<'EOF'
T_INVEST_TOKEN_SANDBOX=      # песочница
T_INVEST_TOKEN_READONLY=     # боевой счёт, уровень "Только просмотр"
T_INVEST_TOKEN_FULL=         # боевой счёт, уровень "Торговля" (НЕ "Торговля и переводы")
EOF
chmod 600 ~/.config/tinvest/.env
```

Заполните только нужные режимы. CLI читает `.env` только из `~/.config/tinvest/.env`, а не из
текущей папки, поэтому работает одинаково из любой директории. Настоящие переменные окружения
важнее файла, это штатный способ для CI и контейнеров. Без токена будет ошибка
`APP_TINVEST_TOKEN_MISSING`, значений по умолчанию нет. Уровень "Торговля и переводы" **не нужен**,
переводов и выводов денег CLI не делает.

## Реальные деньги

Сам по себе full-токен **не** разрешает торговать. Реальные сделки включаются флагом в окружении,
и каждая требует подтверждения. Эти ступени проверяются в коде до обращения к API.

| Режим или флаг | Что происходит |
|---|---|
| `readonly` | Любая сделка запрещена, `APP_TINVEST_TRADING_FORBIDDEN` |
| `sandbox` | Виртуальные сделки свободны |
| `full` без флага | Только чтение, сделка даёт `APP_TINVEST_TRADING_DISABLED` |
| `full` и `T_INVEST_ALLOW_TRADING=true` | Сделка требует подтверждения `--confirm`, иначе `APP_TINVEST_CONFIRM_REQUIRED` |
| `full` и `T_INVEST_STONKS_MODE=true` | **Опасно.** Сделки без подтверждений, полностью автономно |

Что защищает деньги.

- **Подтверждение каждой сделки.** Агент ставит `--confirm` только после того, как вы явно
  согласовали конкретную заявку.
- **Проверка ликвидности.** Перед реальной рыночной заявкой проверяются стакан и спред. На
  неликвиде или широком спреде заявка блокируется, и агент предлагает лимитную.
- **Ключ идемпотентности** (`--order-id`) не даёт заявке задвоиться при повторе после сетевого сбоя.
- **Журнал сделок.** Каждая операция, реальная или в песочнице, дописывается в
  `~/.config/tinvest/trades.log` со временем, режимом, бумагой, лотами, ценой и номером заявки.

**Деньги нельзя вывести со счёта.** Токен уровня "Торговля" и отсутствие в коде методов перевода и
вывода оставляют только операции с бумагами внутри самого счёта. Честная оговорка: разделение
режимов и флаг торговли защищают штатные пути, а не криптографию. Владелец окружения может включить
флаг сам, но это осознанное действие.

<details>
<summary>Как это работает внутри</summary>

<br>

- **Активный режим запоминается.** В начале каждого диалога скилл спрашивает режим и
  перезаписывает выбор, чтобы новый запуск или другая сессия не унаследовали его молча. Память
  нужна для удобства внутри диалога и чтобы пережить потерю контекста, а источник правды это
  `session status`. Пока режим не подтверждён, команды с данными не выполняются
  (`APP_TINVEST_SESSION_REQUIRED`). Переключиться можно в любой момент командой
  `session start --mode <режим>`.
- **Несколько агентов сразу.** Если под одним пользователем одновременно работают несколько
  агентов, задайте каждому свой `TINVEST_SESSION_ID`, и их режимы не будут перезаписывать друг
  друга. Одному агенту это не нужно.
- **Кэш.** Списки инструментов хранятся сутки, графики купонов неделю, в `~/.config/tinvest/cache`.
  После первого прогона скринеры и структура портфеля работают за доли секунды. Кэш можно
  безопасно удалить целиком.
- **Ошибки.** Любая ошибка выводится по-русски со стабильным кодом `APP_TINVEST_...`, технические
  подробности видны при запуске с `TINVEST_DEBUG=1`.
- **Правила для агента** (режимы, подтверждение сделок, должная осмотрительность, расшифровка полей
  JSON) лежат в `SKILL.md` и `references/` внутри пакета, и агент обязан им следовать.

</details>

## Дисклеймер

Это инструмент доступа к данным и операциям T-Invest API. Он **не является услугой
инвестиционного консультирования и не предоставляет индивидуальных инвестиционных рекомендаций
(ИИР)**. Данные и расчёты предоставляются "как есть", в информационных целях. Все инвестиционные
решения и сделки на усмотрение и под ответственность пользователя. Аналитика (доходности,
скринеры, прогнозы аналитиков) это данные и вычисления, а не рекомендации к покупке или продаже.
